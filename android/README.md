# PokéSurvivor 한국어 Android 테스트 앱

앱 0.1.1-test / 내장 번역팩 0.4.3 / 패키지 io.github.guenohpark.pokesurvivorko

## 실행 방식

공식 https://pokesurvivor.com/ 을 Android WebView에서 직접 엽니다. 게임을 복제하거나 다른 게임 서버로 연결하지 않습니다. APK에 내장한 화면 번역 스크립트를 공식 HTTPS 게임 페이지에서만 실행하며 DOM·Canvas 번역을 설치합니다. 주소창 없는 전체 화면이며 터치 기기의 한글 폰트는 90%입니다.

Google Play 또는 원본 게임 개발팀의 공식 앱이 아닌 비공식 비상업 테스트 APK입니다. Nintendo/GAME FREAK 및 원본 운영자와 무관합니다.

## 설치와 조작

1. Android 기기에서 제공된 APK를 받아 엽니다. 설치 출처 허용이 필요하면 해당 다운로드 앱에만 권한을 허용합니다. Play Protect 등의 보안 기능을 끄지 마세요.
2. 인터넷에 연결된 상태에서 공식 게임과 한글 패치 로딩이 끝날 때까지 기다립니다.
3. Android 뒤로 가기는 앱 메뉴를 엽니다. 메뉴에서 계속·재시도·앱 정보·종료를 선택할 수 있습니다.
4. 앱 정보에서 번역 버전, Canvas 훅, 한글 배율과 업데이트 상태를 확인할 수 있습니다. 앱 업데이트 메뉴는 새 APK 다운로드를 안내하지만 직접 설치하지 않습니다.

API 23(Android 6.0) 이상이 설치 대상이지만 최신 Android System WebView를 권장합니다. 실제 기기 호환 범위를 확인한 것은 아닙니다.

## 꼭 알아둘 제한

- Android 기기/에뮬레이터에서 설치·로그인·실제 게임 플레이를 검증하지 않았습니다. 테스트 후 사용하세요.
- Google/팝업 로그인은 지원하지 않습니다. 일반 사용자명·비밀번호 로그인 및 클라우드 기록 연동도 실제 기기 검증이 필요합니다. 로그인 제한을 우회하지 않습니다.
- 앱의 WebView는 기존 Chrome/Safari/PWA와 저장 공간을 공유하지 않습니다. 기존 브라우저의 로컬 기록과 로그인 상태는 자동으로 옮겨지지 않습니다. 공식 계정의 클라우드 기록이 앱에서 복원된다고 아직 보장하지 않습니다.
- 앱은 시작/업데이트 때 저장소를 지우지 않습니다. 앱 삭제 또는 OS의 저장 공간 삭제는 앱의 로컬 기록/로그인 상태를 제거합니다.
- 번역팩은 GitHub 버전을 자동 확인하고 새 버전을 전용 캐시에 받습니다. 진행 중인 화면에 끼워 넣지 않고 다음 불러오기에 적용합니다. 오프라인에서는 정상 캐시 또는 내장본으로 동작합니다. 실패한 후보는 무효화하고 이전 정상본으로 돌아갑니다. APK 자체는 별도로 새 버전을 확인하며 앱 메뉴에서 GitHub 다운로드를 열어 사용자가 설치합니다. 자동 설치하지 않습니다.
- 메뉴/백그라운드에서 WebView 타이머를 중지하지만 게임의 서버·오디오·진행이 완전히 일시 정지된다는 보장은 없습니다. 프로세스 종료 시 진행 중인 판을 복원하지 못할 수 있습니다.
- 팝업, 앱 내 다운로드, 파일 선택·가져오기는 이 버전에서 지원하지 않습니다.
- 게임 자체 업데이트로 화면/번역이 바뀔 수 있습니다. APK는 게임 수치·전투 로직·계정 저장·랭킹 제출 코드를 수정하지 않습니다.

## 확인한 것

- Android SDK 35 플랫폼으로 Java 컴파일 및 D8 변환 성공
- APK v1/v2/v3 서명 검증, ZIP 무결성과 정렬 검사 통과
- 공식 출처 제한 18개 입력 테스트, 번역팩 업데이트/캐시 20개 시나리오, APK 버전 메타데이터 검사 통과
- 내장 스크립트의 DOM/Canvas 설치 상태를 데스크톱 Chromium의 공식 페이지에서 확인
- 위 검사는 Android WebView의 실제 실행 시험을 대신하지 않습니다

## 보안과 개인정보

INTERNET 권한만 사용합니다. 보안 연결 오류를 우회하지 않고, HTTP·파일·content 접근·혼합 콘텐츠·네이티브 JavaScript 브리지를 허용하지 않습니다. 카메라·마이크·위치 등의 권한은 요청/허용하지 않습니다. 공식 게임의 HTTPS 보조 프레임은 허용하되 브라우저의 출처 격리는 유지합니다. 번역 코드는 메인 공식 게임 페이지에서만 실행합니다.

APK가 계정 입력값을 수집하거나 별도 서버로 전송하는 기능은 없습니다. 게임 자체의 공식 서버 통신은 별개입니다. Android 자동 백업은 비활성화합니다.

## 로컬 빌드 (현재 스크립트: macOS Apple Silicon)

Node.js와 기본 curl/tar/unzip가 필요합니다. 소스에는 도구 다운로드 메타데이터만 포함되며 SDK/JDK 바이너리는 포함하지 않습니다.

```sh
node download-tools.cjs
node build.cjs
```

공식 Temurin JDK 17과 Google SDK 패키지를 작업 폴더에 다운로드하고 제공된 체크섬을 검증합니다. 시스템 Java/SDK 설정은 바꾸지 않습니다. 플랫폼 API만 사용하며 Gradle/AndroidX 의존성은 없습니다.

결과: build/pokesurvivor-ko-android-0.1.1-test.apk

서명용 로컬 키는 기본 .local-signing/ 또는 SIGNING_HOME에 생성합니다. 키/비밀번호를 저장소나 배포 ZIP에 넣지 마세요. 후속 APK로 앱을 업데이트하려면 같은 서명키를 유지해야 합니다. 제공된 테스트 APK의 개인키는 이 소스 ZIP에 포함하지 않습니다. 자체 새 키로 만든 APK는 기존 테스트 앱 위에 업데이트 설치되지 않을 수 있습니다.
