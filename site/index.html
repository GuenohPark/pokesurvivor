아래에서 사용할 기기의 안내를 확인하세요. 모든 기기에서 설치 파일은 같습니다.

PC · Chrome / Edge / Firefox

  1. Tampermonkey를 설치하세요.

    공식 Tampermonkey 사이트 →에서 현재 브라우저에 맞는 확장을 선택하세요. 브라우저나 확장 설정에 따라 ‘사용자 스크립트 허용’ 등의 별도 설정이 필요할 수 있습니다.

  2. 통합 스크립트 하나만 추가하세요.

    위의 ‘통합 스크립트 설치’를 누르고 Tampermonkey 설치 화면에서 내용을 확인한 뒤 설치하세요.

  3. 공식 게임을 직접 여세요.

    pokesurvivor.com 열기 →. 기존 게임 탭은 진행 중인 판을 마친 뒤 새로고침하세요.

Android · Firefox + Tampermonkey

  1. Firefox와 Tampermonkey를 준비하세요.

    공식 Firefox 설치 → 후 Firefox에서 Tampermonkey 확장 →을 추가하세요. 모바일 설치 경로가 보이지 않으면 공식 Firefox용 안내 →를 확인하세요.

  2. Firefox에서 통합 스크립트를 설치하세요.

    이 페이지를 Firefox로 열고 위 설치 링크를 누르세요. Tampermonkey의 설치 확인과 필요한 권한 설정을 완료하세요.

  3. 같은 Firefox에서 게임을 여세요.

    공식 .com 게임 열기 →. 다른 브라우저나 기존 APK에 설치되는 방식은 아닙니다. 실기기별 작동과 로그인 성공을 보장하지 않습니다.

iPhone / iPad · 일반 Safari 탭

  1. Safari용 Tampermonkey를 설치하세요.

    공식 App Store 앱 →은 iOS 15 이상 Safari를 지원합니다. 구매가 필요할 수 있으며 현재 가격과 기기 호환성을 스토어에서 확인하세요.

  2. 확장과 사이트 접근 권한을 켜세요.

    iPhone / iPad 설정의 Safari → 확장 프로그램에서 Tampermonkey를 활성화하세요. pokesurvivor.com 사이트 접근을 허용하고, Safari에서 위 통합 스크립트 설치를 확인하세요. 설정 경로는 OS 버전에 따라 다를 수 있습니다.

  3. 홈 화면 웹앱 대신 Safari 탭을 사용하세요.

    공식 .com 게임 열기 →를 일반 Safari 탭에서 여세요. 독립 PWA에서의 확장 작동은 보장하지 않습니다. 실제 iOS 기기에서 통합 번들 전체 흐름은 아직 미검증입니다.

기존 패치는 먼저 꺼주세요. 이전 패치, 자동 로더, 커스텀 확장과 함께 사용하면 중복 실행될 수 있습니다. 새 통합 스크립트 하나만 켜세요.

UPDATES

설치 후에는 관리자에서 갱신

처음에는 관리자와 스크립트를 각각 설치해야 합니다. 이후 업데이트는 Tampermonkey의 업데이트 확인 주기와 설정을 따르며 즉시 적용되지 않습니다.

iOS의 백그라운드 중단, 추가 승인이나 권한 설정 때문에 지연될 수 있습니다. 필요하면 관리자의 업데이트 확인을 사용하고, 진행 중인 판을 마친 뒤 새로고침하세요.

SCOPE & LIMITS

번역 범위는 솔직하게

DOM 번역과 함께 Canvas 번역을 페이지 실행 영역(page world)에서 시도합니다. CSP, 대체 실행 경로(fallback), 격리된 실행 영역 때문에 Canvas 적용은 보장되지 않으며, 특히 실제 iOS는 미검증입니다.

공식 pokesurvivor.com의 최상위 페이지 전용입니다. .org, iframe, 인증 페이지는 제외하며 로그인·저장 로직은 수정하지 않습니다.

막혔을 때 확인하기

설치 링크를 눌렀는데 코드만 보여요.

관리자가 해당 브라우저에 설치되고 활성화되어 있는지 확인하세요. 파일을 저장했다면 Tampermonkey의 가져오기 기능으로 .user.js 파일을 추가할 수 있습니다. 이 페이지는 Tampermonkey 설치 여부를 감지하지 않습니다.

기기 추천이 맞지 않아요.

기기 표시는 브라우저가 제공한 UA·플랫폼·터치 정보에 따른 참고용입니다. UA를 변경하거나 위장하지 않습니다. 위 PC / Android / iPhone 탭에서 직접 바꿀 수 있으며, 설치 파일은 동일합니다.

다른 설치 방식도 남아 있나요?

기존 배포물은 삭제하지 않습니다. Chrome ZIP·수동 설치 안내 →와 Android APK·제약 안내 →를 확인하세요. 이들은 별도 배포물이며 통합 스크립트와 동시에 켜지 마세요.
