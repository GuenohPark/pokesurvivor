아래에서 사용할 기기를 선택하세요. PC·Android는 통합판, 아이폰은 무료 Userscripts용 자동 로더를 사용합니다.

PC · Chrome / Edge / Firefox

  1. Tampermonkey를 설치하세요.

    공식 Tampermonkey 사이트 →에서 현재 브라우저에 맞는 확장을 선택하세요. 브라우저나 확장 설정에 따라 ‘사용자 스크립트 허용’ 등의 별도 설정이 필요할 수 있습니다.

  2. 통합 스크립트 하나만 추가하세요.

    위의 ‘PC·Android 통합 스크립트 설치’를 누르고 Tampermonkey 설치 화면에서 내용을 확인한 뒤 설치하세요.

  3. 공식 게임을 직접 여세요.

    pokesurvivor.com 열기 →. 기존 게임 탭은 진행 중인 판을 마친 뒤 새로고침하세요.

Android · Firefox + Tampermonkey

  1. Firefox와 Tampermonkey를 준비하세요.

    공식 Firefox 설치 → 후 Firefox에서 Tampermonkey 확장 →을 추가하세요. 모바일 설치 경로가 보이지 않으면 공식 Firefox용 안내 →를 확인하세요.

  2. Firefox에서 통합 스크립트를 설치하세요.

    이 페이지를 Firefox로 열고 위 설치 링크를 누르세요. Tampermonkey의 설치 확인과 필요한 권한 설정을 완료하세요.

  3. 같은 Firefox에서 게임을 여세요.

    공식 .com 게임 열기 →. 다른 브라우저나 기존 APK에 설치되는 방식은 아닙니다. 실기기별 작동과 로그인 성공을 보장하지 않습니다.

iPhone / iPad · Safari + 무료 Userscripts

  1. 무료 Userscripts 앱을 설치하세요.

    App Store의 Userscripts →를 설치하고 앱에서 스크립트 저장 폴더를 확인하거나 지정하세요.

  2. Userscripts용 자동 로더 하나만 저장하세요.

    아이폰 자동 로더 받기 →를 길게 눌러 링크된 파일을 다운로드하고 Userscripts의 지정 폴더에 넣으세요. 파일명은 pokesurvivor-ko-auto.user.js 그대로 유지하고 .txt를 붙이지 마세요. PC·Android 통합 파일이 아닌 이 자동 로더를 사용합니다.

  3. Safari 확장을 켜고 .com만 허용하세요.

    설정 → Safari → 확장 프로그램에서 Userscripts를 켜고 pokesurvivor.com만 허용하세요. 설정 경로는 OS 버전에 따라 다를 수 있습니다. 공식 .com 게임 열기 →를 일반 Safari 탭에서 열어 Userscripts 메뉴의 자동 로더만 켜세요. 기존 .org 권한은 끄고 진행 중인 판을 마친 뒤 새로고침하세요.

아이폰 Userscripts는 메뉴·도감·게임 중 기술 선택·일시정지 기술 목록 등 DOM 번역용입니다. 전투 Canvas HUD는 번역되지 않으며 독립 PWA는 지원하지 않습니다. 새 로더의 실제 iPhone 전체 흐름은 미검증입니다.

기기에 맞는 패치 하나만 켜세요. PC·Android는 통합 스크립트, 아이폰은 Userscripts 자동 로더만 켜세요. 이전 패치·전체 번역팩·커스텀 확장과 동시에 사용하지 마세요.

UPDATES

설치 후에는 관리자에서 갱신

처음에는 관리자와 스크립트를 각각 설치해야 합니다. PC·Android 통합판은 Tampermonkey의 업데이트 주기와 설정을 따릅니다. 아이폰 자동 로더는 접속 시 번역팩을 확인하고 캐시하며, 사용자가 입력한 뒤 찾은 업데이트는 다음 새로고침 때 적용합니다.

iOS의 백그라운드 중단, 추가 승인이나 권한 설정 때문에 지연될 수 있습니다. 같은 Safari 탭을 오래 열어 둔 것만으로 새 버전이 확인되지는 않을 수 있습니다. 진행 중인 판을 마친 뒤 새로고침하세요.

SCOPE & LIMITS

번역 범위는 솔직하게

PC·Android 통합판은 DOM과 Canvas 번역을 페이지 실행 영역(page world)에서 시도하지만 CSP·대체 실행 경로(fallback)에 따라 달라집니다. 아이폰 무료 Userscripts 경로는 DOM 전용이며 전투 Canvas HUD는 번역되지 않습니다.

공식 pokesurvivor.com의 최상위 페이지 전용입니다. .org, iframe, 인증 페이지는 제외하며 로그인·저장 로직은 수정하지 않습니다.

막혔을 때 확인하기

설치 링크를 눌렀는데 코드만 보여요.

아이폰은 자동 로더 링크를 길게 눌러 다운로드한 뒤 Userscripts의 지정 폴더에 저장하세요. PC·Android는 Tampermonkey의 가져오기로 통합 .user.js 파일을 추가할 수 있습니다. 이 페이지는 Userscripts 또는 Tampermonkey 설치 여부를 감지하지 않습니다.

기기 추천이 맞지 않아요.

기기 표시는 브라우저가 제공한 UA·플랫폼·터치 정보에 따른 참고용입니다. UA를 변경하거나 위장하지 않습니다. 위 PC / Android / iPhone 탭에서 직접 바꿀 수 있으며, 아이폰 탭에서는 Userscripts 자동 로더, PC·Android 탭에서는 Tampermonkey 통합 파일로 설치 버튼이 바뀝니다. JavaScript가 꺼져 있어도 아이폰 전용 링크를 직접 사용할 수 있습니다.

다른 설치 방식도 남아 있나요?

기존 배포물은 삭제하지 않습니다. Chrome ZIP·수동 설치 안내 →와 Android APK·제약 안내 →를 확인하세요. 이들은 별도 배포물이며 통합 스크립트와 동시에 켜지 마세요.
