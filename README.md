# PokéSurvivor 한국어 패치

[스크립트 설치 / 다운로드](https://raw.githubusercontent.com/GuenohPark/pokesurvivor/main/pokesurvivor-ko-menu.user.js) · [게임 팁 15개와 근거](TIPS.md) · [변경 이력](CHANGELOG.md)

공식 게임은 그대로, 메뉴는 한국어로. **pokesurvivor.org/play/**에서, 아이폰 Safari의 Userscripts 확장으로 사용하는 비공식 UI 패치입니다. 한글에는 갈무리11 도트 폰트를 적용하고, 영문에는 게임의 원래 폰트를 유지합니다. 눌러서 시작 화면에는 소스로 확인한 게임 팁이 무작위로 표시됩니다.

> 현재는 **메뉴 번역 시험판**입니다. 전체 게임 번역이 아닙니다. Nintendo, GAME FREAK 또는 PokéSurvivor 개발팀과 무관합니다.

## 접속 주소와 권한

기본 사용 주소: **https://pokesurvivor.org/play/**

확인한 페이지 구조는 .org 바깥 페이지 안에 .com 게임을 iframe으로 넣는 방식입니다. 따라서 패치의 @match와 Safari 권한은 **.org와 .com을 모두** 포함합니다. .com 직접 접속도 지원하지만 기본 설치 안내는 .org 기준입니다. 사이트를 복제하거나 다른 서버로 게임 데이터를 보내지 않습니다.

## 무엇이 바뀌나요?

- 플레이·강화·뽑기·도감·설정 등 주요 메뉴와 일부 UI 문구
- 나중에 열리는 메뉴의 텍스트도 감지하여 번역
- 한글 도트 폰트: 갈무리11 일반/굵게. 폰트가 파일 안에 있어 별도 설치나 외부 폰트 서버 연결이 필요하지 않습니다.
- 시작 화면의 **그거 아셨나요?** 랜덤 팁 15개와 다음 팁 버튼
- 영문 글꼴과 게임 로직은 그대로 유지

게임 화면(Canvas HUD), 기술·아이템 전체 설명, 모든 포켓몬 이름은 번역하지 않습니다.

## 아이폰 설치

1. App Store에서 [Userscripts](https://apps.apple.com/us/app/userscripts/id1463298887)를 설치합니다.
2. Userscripts 앱에서 스크립트 저장 폴더를 확인하거나 지정합니다.
3. [pokesurvivor-ko-menu.user.js 내려받기](https://raw.githubusercontent.com/GuenohPark/pokesurvivor/main/pokesurvivor-ko-menu.user.js)를 열어 설치하거나 파일로 내려받아 그 폴더에 저장합니다. GitHub 파일 화면의 Raw 또는 다운로드 기능을 사용하세요. 웹페이지 HTML을 저장하지 않도록 주의하세요.
4. iPhone 설정 → 앱 → Safari → 확장 프로그램에서 Userscripts를 켜고 **pokesurvivor.org와 pokesurvivor.com 두 사이트** 접근을 허용합니다. iOS 버전에 따라 설정 경로가 다를 수 있습니다. 모든 사이트 접근 권한은 필요하지 않습니다.
5. Safari에서 [PokéSurvivor 플레이](https://pokesurvivor.org/play/)을 열고, 페이지 메뉴 → 확장 프로그램 → Userscripts를 **한 번 엽니다**. 파일을 추가·교체한 뒤에는 이 단계가 필요합니다.
6. 목록에서 **PokéSurvivor 한국어 메뉴 시험판**을 켜고 게임 페이지를 새로고침합니다. 플레이·강화·뽑기로 바뀌면 성공입니다.

이름 끝은 반드시 **.user.js**여야 합니다. .txt나 .html이 붙지 않게 해주세요.

## 그거 아셨나요?

시작 화면에 적 포화, 보스전, 상자, 제단, 샘, 리프트, 결속, 기술 진화, 뮤츠의 물리/특수 효율 등 검증한 팁 15개가 무작위로 표시됩니다. 다음 팁 버튼으로 다른 내용을 볼 수 있습니다. 버튼 밖의 시작 화면을 누르면 원래 게임으로 들어갑니다.

예: 적이 **이미 55마리 이상**일 때 **새로 생성되는 일반 적**의 체력은 1.6배, 공격 피해는 1.25배가 됩니다. 65마리가 되면 기존 적 전체가 강해진다는 뜻이 아닙니다.

[TIPS.md](TIPS.md)에 모든 조건·공개 소스 링크·확인일을 기록했습니다. 미확인 히든코드나 개발자 테스트 코드는 넣지 않았습니다. 브라우저가 음악 재생을 이미 허용한 경우 게임 자체가 눌러서 시작 화면을 건너뛸 수 있어 팁도 보이지 않을 수 있습니다.

## 업데이트

배포 스크립트의 @version, @updateURL, @downloadURL을 사용합니다. 새 버전이 올라오면 Userscripts의 업데이트 확인/알림 기능으로 적용할 수 있습니다. **게임 중 즉시 반영되는 강제 자동 업데이트는 아닙니다.** 앱 버전·설정에 따라 확인 시점과 조작이 달라질 수 있습니다. 업데이트 후 페이지를 새로고침하세요.

기존에 채팅에서 받은 v0.1/v0.2 파일에는 업데이트 주소가 없습니다. GitHub 배포본으로 **최초 한 번 교체**해야 합니다.

업데이트가 표시되지 않으면 최신 .user.js를 같은 이름으로 교체 → Userscripts 팝업 열기 → 게임 새로고침 순으로 수동 업데이트할 수 있습니다.

[Userscripts 공식 설치·업데이트 문서](https://github.com/quoid/userscripts#usage)

## 영어로 계속 나오나요?

- 기본 접속 주소는 **https://pokesurvivor.org/play/**입니다. 이 페이지는 https://pokesurvivor.com/ 게임을 iframe으로 불러옵니다. **두 도메인 모두 Userscripts 접근 허용**이 필요합니다. 팝업에서 패치가 **sub**(내부 프레임)으로 표시될 수도 있습니다.
- Userscripts에 **Demo user script**만 보이면 한국어 패치가 인식되지 않은 것입니다. 파일이 앱의 지정 폴더에 있는지 확인하세요.
- 팝업의 전체 주입 스위치와 한국어 패치 스위치를 켭니다.
- iCloud 폴더라면 파일 다운로드/동기화 여부도 확인하세요.
- 홈 화면 앱이나 앱 내 브라우저 대신 Safari에서 먼저 시험하세요.
- 원래 영어 메뉴가 잠깐 보인 뒤 바뀔 수 있습니다.

## 보안 및 범위

- 화면의 DOM 텍스트와 한글 글꼴만 바꿉니다.
- 계정 정보, 비밀번호, 쿠키, 게임 저장 데이터에 접근하지 않습니다.
- 게임 상태·공격력·점수·랭킹 코드·서버 요청을 수정하지 않습니다.
- 패치 자체는 외부 네트워크 요청이나 분석/추적 기능을 포함하지 않습니다. 게임과 Userscripts의 통신은 각각 별개입니다.
- 서버 검증 또는 랭킹 정책상 허용 여부를 보증하지 않습니다.

## 확인된 환경과 한계

- 데스크톱 Chromium의 공식 사이트에서 메뉴·동적 설정 화면 번역과 폰트 로딩을 확인했습니다.
- 사용자가 iPhone에서 메뉴 번역이 작동한다고 확인했습니다.
- **도트 폰트·팁 UI·온라인 업데이트는 iPhone 실기기에서 아직 검증하지 않았습니다.** 데스크톱에서는 **.org/play/의 .com 내부 프레임**에서 번역·글꼴·팁 전환·정상 시작 동작을 확인했습니다.
- 공식 사이트 UI나 보안 정책이 바뀌면 패치 보완이 필요할 수 있습니다.

## 제거

Userscripts에서 스크립트를 끄거나 삭제한 뒤 새로고침합니다. 게임 저장 데이터는 바꾸지 않습니다.
