# 최신 기술·문구 번역 감사 · 패치0.4.8

2026-10-20에 공식 게임의 moves.js, items.js, pokedex.js, lang-en.js와 현재 저장소 HEAD `018e986f4c12f414dfa84193ee35b2959b1e325c`를 확인했습니다. 종전 명칭 사전은 기본 기술65개·진화 명칭59개 기준이어서 이후 추가된 기본 기술38개와 진화 명칭38개가 빠져 있었습니다.

## 반영
- 현재 기본 기술103개, 진화 명칭97개, 장착 아이템11개의 이름을 대조했습니다.
- 파괴광선(Hyper Beam), 에너지볼(Energy Ball), 깜짝베기(Night Slash) 등 새 명칭을 PokéAPI의 공식 한국어 행과 대조했습니다. 명칭 자료의 고정 revision·언어 ID·CSV 해시는 `data/names-provenance.json`에 있습니다.
- 새 기술 설명38개와 강화·진화·시작 기술 선택·단일 타입 보너스·랭킹 등의 문구를 합쳐75개 추가했습니다. 기존 Tipo의 새 영문 별칭 Type도 보완했습니다.
- Psychic은 타입에서 에스퍼, 기술에서 사이코키네시스로 구분합니다. 시작 기술 선택/안내와 단일 타입 보너스 문구의 자리표시자에도 문맥을 지정했습니다. 계정/입력값/게임 수치는 바꾸지 않습니다.
- Swarm/Enjambre는 게임에서 진화 기술로 빌려 쓰는 공식 특성명 벌레의알림입니다. 공식 본가 기술이라고 재분류하지 않았습니다.

## 원본 언어별 명칭 충돌1건
원본 스페인어 `Voltio Cruel`은 공식 Wild Charge(와일드볼트, 기술528)인데, 게임 영문 사전은 이를 `Volt Tackle`(볼트태클, 기술344)로 표시합니다. 하나의 공식 정체성을 임의로 단정하지 않고, 보이는 스페인어/영어 명칭 각각의 공식 한국어 뜻을 유지했습니다. 이 충돌은 provenance에 별도 기록했습니다.

## 검증 및 한계
`npm test`에는 현재 영문 사전1,374쌍, 기본 기술103개와 진화 명칭97개, 기술/아이템 설명114개, 강화412단계를 확인하는3,799개 검사가 추가되어 있습니다. 원본 목록·출처 해시는 `tests/fixtures/current-game-translations.json`, 결과는 `tests/reports/current-translations.json`입니다. Google 상표 및 PC 표기는 의도적으로 그대로 둡니다.

이 검사는 캡처한 목록과 사전의 번역 누락 방지용이며 모든 동적 문장을 완전 번역한다는 보장이 아닙니다. 물리적 iPhone Safari/Userscripts 실행 검증도 아닙니다. Safari 전투 상단의 Canvas 기술명·격파 수 등은 현재 자동 JS가 그림판을 수정할 수 없어 여전히 영문이 남을 수 있습니다. DOM 카드·설명·메뉴의 누락과는 별개의 제약입니다.

개발자가 `npm run audit:live`를 실행하면 현재 공개 데이터4개를 읽어 새 기본/진화 기술명·포켓몬명·영문 사전의 정확 일치 키 누락을 확인할 수 있습니다. 저장된 회귀 테스트만으로 미래의 원본 변경을 자동 감지하는 것은 아니므로 이 별도 최신 소스 감사가 필요합니다. 계정·저장·인증 API는 조회하지 않습니다.

기존 자동 로더0.1.1은 재설치하지 않습니다. 판을 끝낸 뒤 새로고침하여 `한국어 v0.4.8`을 확인하고, 업데이트 준비됨이면 다음 새로고침 때 적용합니다. GitHub Chrome 수동 설치판은0.1.5이며 기존 스토어 제출본0.1.3과 다릅니다. 이번 변경으로 스토어 심사를 취소하거나 재제출하지 않았습니다.
