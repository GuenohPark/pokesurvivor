# 상점·성격·특성·TM 호환성 점검

## 배포 상태

0.5.4를 기준으로 만든0.5.5 번역·UI 호환성 릴리스입니다. 브라우저/Chrome 수동판0.1.13, iPhone 자동 로더0.1.2는 변경하지 않았습니다. 스토어 제출본과 APK는 이번 배포 대상이 아닙니다. 공개 배포 성공은 CI·Pages·번들 지문으로 별도 확인하며 실기기 검증과 구분합니다.

## 확인·보완

- 켈리몬 상점/가방/기술머신/민트/일반·숨겨진 특성 캡슐/효과/구매 불가·수량·습득 알림·업데이트 안내를 보완했습니다. 신규182항목, 총1700항목입니다.
- 공식 한국어 명칭은 고정 PokeAPI 한국어 행에서271특성/25성격을 연결했습니다. 별도 문맥 사전으로만 적용해 Potencia/Imán/Rara 같은 도구·강화·희귀도 단어와 혼동하지 않습니다. data/catalog-names-provenance.json 참조.
- 원본의 translate=no 중 새 도감 성격·특성 이름만 좁게 허용합니다. 닉네임·???·입력·일반 보호 영역은 넓히지 않습니다.
- 기술머신 Psychic은 사이코키네시스, 타입 Psychic은 에스퍼로 구분합니다.
- 두 번째 시작 기술의 표시/배지를 지원하고, 무작위 선택은 미평가 기술로 취급하지 않습니다. 기존 기술폭 강화 명칭과 통일했습니다.
- 등급/평가 데이터는 수정하지 않고 성격·선택/숨겨진 특성·학습 TM 미반영 조건을 도구말에 명시했습니다.

## 검증

고정 원본 ce5785313b0205af8b9477423f64b0a7b7039dcd의 Git blob/SHA256을 확인했습니다. npm build/test와 Chrome58 정적/VM 검사가 통과했습니다. 신규4,914 데이터 조건에서149종 실제 효과 설명 및 d2, 25성격/271특성의 원본6언어 별칭을 검증했습니다. 기존 보호63파일·로더·등급 데이터는 바이트 지문이 동일합니다.

실제 브라우저에서는 localhost의 격리 합성 UI에 원본 HTML 생성기를 사용해 ES/EN 재렌더링, 성격24선택/특성2선택, 기술머신의 문맥 번역을 확인했습니다. 원본 규칙대로 자연 기술을 TM에서 제외합니다(팬텀의 TM 사이코키네시스, 뮤의 TM 섀도볼). 합성 재고이며 실제 그날의 판매 목록이 아닙니다.

## 미검증/경계

실제 게임·계정·구매·가방 소비·저장·로그인·클라우드에 접근하지 않았습니다. 실기기/실제 확장 설치/원본 전체 CSS·상점 애니메이션·모바일 배치를 검증한 것은 아닙니다. 격리 화면은 간소화 CSS와 대체 아이콘이며 원본 부팅/Canvas 훅이 없습니다. iPhone 무료 Userscripts의 Canvas 제한도 그대로입니다.

추가 원본4bd9283c의 협동 방 연결 복구 변경도 검토했습니다. 상점·도감·성격·특성 데이터 구조에는 변경이 없으며 최신 업데이트 안내의 한국어 문구만 추가했습니다. 네트워크 복구 로직 자체는 원본 게임의 변경이며 이 패치가 수정하지 않습니다.
