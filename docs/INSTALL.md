# 아이폰 설치와 업데이트

[설치 파일 받기](https://raw.githubusercontent.com/GuenohPark/pokesurvivor/main/dist/pokesurvivor-ko-auto.user.js) · [처음 화면](../README.md) · [PWA 안내](PWA.md)

## 설치 파일은 하나만

권장 파일은 **pokesurvivor-ko-auto.user.js**입니다. dist의 meta.js나 개발 소스는 설치하지 않습니다. 전체 번역팩은 로더가 필요할 때 GitHub에서 내려받아 보관합니다.

1. App Store에서 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)를 설치합니다.
2. Userscripts 앱에서 스크립트 저장 폴더를 확인하거나 지정합니다.
3. 위 링크를 Safari에서 열어 설치하거나 링크를 길게 눌러 파일을 내려받아 그 폴더에 저장합니다. 파일 끝은 **.user.js**여야 하며 .txt나 .html을 붙이지 않습니다.
4. 설정 → 앱 → Safari → 확장 프로그램에서 Userscripts를 켭니다. iOS 버전에 따라 설정 경로가 다를 수 있습니다.
5. **pokesurvivor.org와 pokesurvivor.com 둘 다** 사이트 접근을 허용합니다.
6. [게임](https://pokesurvivor.org/play/)을 일반 Safari 탭에서 엽니다. Safari 확장 메뉴 → Userscripts를 한 번 열어 **‘PokéSurvivor 한국어 자동 업데이트’만** 켭니다. 이전 메뉴 시험판·전체 번역팩은 끕니다.
7. 페이지를 새로고침하고 도감의 **뮤츠 / 특수공격 / 염동력** 표시를 확인합니다.

.org/play/는 .com 게임을 iframe으로 띄웁니다. 목록에 내부 프레임을 뜻하는 sub 표시가 있을 수 있습니다. 두 도메인 권한을 주지 않으면 바깥 페이지 또는 게임 내부만 적용되지 않을 수 있습니다.

## 현재 Safari 패치

- **번역팩 0.4.7 / 자동 로더 0.1.1**입니다. 로더 번호와 실제 번역팩 번호는 다릅니다.
- 메인 파트너·도감 등 글자로 표시되는 이름 옆에 등급 또는 `미평가`를 표시합니다. 미보유 `???`는 그대로 숨깁니다.
- 기존 자동 로더는 다시 설치하지 말고, 게임을 마친 뒤 Safari에서 새로고침해 `한국어 v0.4.7`을 확인하세요. `준비됨`이면 한 번 더 새로고침할 때 적용됩니다.
- 같은 Safari 탭을 오래 열어 두거나 뒤로가기로 복원한 것만으로는 새 버전 확인이 다시 실행되지 않을 수 있습니다.
- 전투 중 Canvas 이름은 이번 DOM 배지 지원 범위가 아닙니다. [범위와 한계](TIERS.md).

## 자동 업데이트 동작

- 접속 시 공개 GitHub의 버전을 확인하고 더 새 번역팩만 받습니다.
- 같은 버전이면 저장한 캐시를 사용합니다. 오프라인에서도 이미 받은 캐시가 있으면 사용합니다. 첫 실행은 번역팩을 내려받을 인터넷 연결이 필요합니다.
- 잘못된 응답·버전 불일치·구버전으로의 다운그레이드는 거부합니다.
- 사용자가 게임을 시작하거나 입력한 뒤 새 버전을 발견하면 현재 판에 끼워 넣지 않고 **다음 새로고침 때** 적용합니다. 진행 중인 판 때문에 새로고침하지 마세요.
- Userscripts 앱 자체 업데이트와 번역팩 업데이트는 별개입니다. 로더 파일 자체가 바뀐 경우 앱의 업데이트 기능을 쓰거나 최신 로더를 다시 저장할 수 있습니다.
- 0.1.0 로더의 기존 루트 주소도 계속 제공합니다. 새 배포 경로는 dist입니다.

## 안 될 때

1. **홈 화면의 독립 PWA인가요?** 일반 Safari 탭으로 같은 게임을 여세요. [PWA 문제와 바로가기 대안](PWA.md)
2. Userscripts 확장과 스크립트가 켜져 있는지, 두 사이트의 접근 권한이 있는지 확인합니다.
3. 자동 로더와 예전 전체 패치를 동시에 켜지 않았는지 확인합니다.
4. 새로 설치했다면 인터넷에 연결된 상태에서 페이지를 한 번 새로고침하고 게임을 시작하기 전에 기다립니다.
5. 메뉴는 한국어지만 전투 HUD가 영어라면 DOM 배포판의 현재 제약일 수 있습니다. 단순 권한 오류로 단정하지 마세요. [지원 범위](COMPATIBILITY.md)

폰트는 번역팩에 내장되어 별도 폰트 앱이 필요하지 않습니다. 0.4.3부터 터치 기기의 한글만 10% 줄이며, 구형 Safari에서 size-adjust를 지원하지 않으면 원래 크기로 남을 수 있습니다. 진행 화면의 Swarm·실시간 격파 수·포켓몬 이름은 Canvas여서 현재 Userscripts 설치만으로 번역되지 않습니다. 이 배포를 위해 게임을 다른 서버로 복제하거나 계정 데이터를 옮길 필요는 없습니다.

## 수동 설치

자동 업데이트를 원치 않으면 [전체 번역팩](https://raw.githubusercontent.com/GuenohPark/pokesurvivor/main/dist/pokesurvivor-ko-menu.user.js)을 대신 설치할 수 있습니다. **자동 로더를 끄고** 사용하고, 이후 새 버전은 직접 교체합니다.

물리적 iPhone에서 0.1.1 로더와 0.4.3 전체 흐름을 직접 검증한 상태는 아닙니다. 기존 메뉴 패치의 iPhone 동작은 사용자가 확인했고, 자동 로더는 Node의 GM 통합 테스트와 공개 배포 파일 검사로 검증했습니다.
