# 개인정보 처리 안내

PokéSurvivor 한국어 패치 · 도감 티어 확장은 공식 게임의 표시용 텍스트와 Canvas 글꼴을 한국어로 변환하고 도감에 참고 티어를 추가하는 비공식 비상업 팬 확장입니다.

- 개인정보, 계정 정보, 비밀번호, 인증 토큰, 쿠키, 결제 정보, 건강 정보, 위치 정보를 외부로 수집·전송·판매하지 않습니다.
- 확장이 직접 실행하는 외부 서버 요청, 분석·광고·추적 도구가 없습니다. 번역과 티어 자료는 설치 패키지에 내장됩니다.
- 표시를 변환하기 위해 공식 게임 문서의 DOM 텍스트와 Canvas 텍스트 등 웹사이트 콘텐츠를 기기 내에서 일시적으로 처리합니다. 이 웹사이트 콘텐츠는 외부 서버에 전송하거나 별도 파일·분석 데이터로 보관하지 않습니다. 게임 계정 저장소·인증정보·강화·코인·저장 데이터는 직접 조회하거나 변경하지 않습니다. 화면에 표시된 문구를 번역하는 기능과 실제 게임 저장 상태를 변경하는 기능은 다릅니다.
- Google/Firebase 인증 화면과 하위 프레임에는 실행하지 않습니다.
- 접근 범위는 HTTPS의 pokesurvivor.com 및 www.pokesurvivor.com 최상위 게임 경로 /, /index.html, /dev.html입니다.
- Chrome Web Store 설치·업데이트 과정에서 Google이 처리하는 정보와 원본 게임이 자체 처리하는 정보는 각각의 서비스 정책을 따릅니다. 이 확장은 그 서비스의 운영자가 아닙니다.
- 확장을 제거하고 게임을 새로고침하면 표시 기능을 중지할 수 있습니다. 게임 저장 데이터를 삭제할 필요는 없습니다.

- 픽업 페이드와 제단 이름 표시를 위해 현재 화면의 위치·종류·사용 표시 등 휘발성 렌더링 값을 기기 내에서 일시적으로 확인하고 그림을 감쌉니다. 실제 보상·아이템 획득·경험치·접촉 판정·계정·저장 로직은 바꾸지 않으며, 이 표시값을 외부로 보내거나 별도 보관하지 않습니다.

문의: https://github.com/GuenohPark/pokesurvivor/issues

대상 확장 0.1.13 / 한국어 패치 0.5.5. 스토어 설치·업데이트 및 원본 게임의 처리는 각 서비스 정책을 따릅니다.

이 문서는 처리 방식을 설명하며 특정 버전의 심사 승인·게시 완료를 뜻하지 않습니다. 현재 게시 버전은 Chrome 웹 스토어의 세부정보를 확인하세요.
