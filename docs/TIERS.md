# 도감 풀강화 잠정 티어

한국어 패치 0.4.5 / Chrome 확장 0.1.2-test부터 도감의 보유 포켓몬 이름 옆에 작은 등급 배지만 표시합니다. 별도 티어 메뉴, 안내 영역, 풀강화 상세 수치 패널은 제거했습니다. 비공식 참고 UI이며 게임 운영자의 공식 티어나 랭킹 등급이 아닙니다.

## 어디서 보나요?

- 게임의 **포켓몬 / 도감**에서 평가된 보유 포켓몬의 이름 옆 **S / A+ / 화력** 배지를 확인합니다. 카드와 선택한 포켓몬의 이름 옆에만 작게 표시합니다.
- 미평가 및 미보유 포켓몬에는 배지를 표시하지 않습니다. 배지가 없다는 것이 낮은 등급을 뜻하지 않습니다.
- 배지에 마우스를 올리면 풀강화 기준 비공식 잠정 평가임을 설명합니다. 평가 기준과 계산 수치는 이 문서와 CSV에서만 확인합니다.
- 미보유 포켓몬의 `???` 이름·실루엣·숨겨진 수치는 해제하지 않습니다. 계정의 강화, 코인, 선택 포켓몬, 저장, 로그인, 실제 전투 수치를 변경하지 않습니다.
- 이전 Chrome 압축해제 설치자는 새 ZIP으로 확장 폴더를 교체하고 확장 관리에서 새로고침한 뒤 게임도 새로고침해야 합니다. 진행 중인 판은 먼저 마치세요. [설치 안내](CHROME-EXTENSION.md)

## 잠정 후보군

같은 등급 안의 순서는 순위를 뜻하지 않습니다. 아래 등급은 계산 수치와 기술 풀을 참고해 선별한 잠정 평가이며, 자동 점수 공식으로 확정한 승률 티어가 아닙니다.

- **S 후보:** 뮤츠, 아르세우스, 게을킹, 레지기가스, 가이오가, 그란돈, 무한다이노
- **A+ 후보:** 마샤도, 팬텀, 쥬피썬더, 제라오라, 테오키스
- **화력 특화:** 전수목, 램펄드. 실제 기술 DPS나 종합 생존력 1위를 뜻하지 않습니다.
- **그 외:** 미평가. 낮은 등급이라는 뜻이 아닙니다.

966종의 수치는 계산했지만 등급을 선별한 것은 14종입니다. 나머지 952종에 근거 없는 B/C/D 등급을 만들지 않았습니다.

## 공통 계산 조건

원본 게임 소스 [803125d](https://github.com/JPTER78/pokesurvivor/tree/803125dfdf3066fe6cf65f490f1e7b577871a295), 2026-10-19 밸런스 기준입니다. `fullmax-v1` 데이터이며 향후 게임 수치가 바뀌면 재검토가 필요합니다.

- **모든 영구 강화 최대:** HP +80, 공격 ×1.4, 속도 ×1.24, 쿨다운 ×0.76, 일반 피해 감소 16%, 재생 +1 HP/s, 치명타 확률 30% / 치명 피해 ×1.5. 경험치·자석·시작 기술 슬롯 등 나머지 영구 강화도 공통 최대치입니다.
- 계정별 실제 강화 차이는 반영하지 않습니다. 계정 저장을 읽어 계산하지 않습니다.
- 아이템·런 성장 카드·일시 버프 없음, 중립 날씨·중립 상성·마른 지형을 가정합니다. HP는 **풀강화로 시작할 때의 HP**이며 런 도중 성장한 HP가 아닙니다.
- 물리/특수 배율과 단일 타입의 자기 타입 기술 +20%를 반영합니다. 학습 가능한 자기 타입 공격의 물리/특수 분류도 확인합니다.
- 30분 이후 속도는 `130 + (130 초과분 × 0.25)`입니다. 심판의 일부 순수 피해는 방어 감소를 무시하므로 일반 유효체력을 그 구간 전체에 적용하면 안 됩니다.

**정규화 공격계수는 실제 DPS가 아닙니다.** 기술의 기본위력과 공격주기를 같다고 놓고, 학습 가능한 자기 타입 공격의 배율에 치명타 기대값과 영구 쿨다운 보정을 적용한 비교 지표입니다. 범위, 관통, 적 수, 명중률, 공격 지속 방식, 충전/투사체 이동, 기술 진화와 유대 조합의 실전 차이는 포함하지 않습니다.

별도 공통 기술 검산은 모든 포켓몬에 같은 Lv.5 미진화 몸통박치기를 적용하고, 중립 방어 75인 단일 적에게 항상 명중한다고 가정한 이론 수치입니다. 이것 역시 실제 런 측정이 아니며, 각 포켓몬의 최적 빌드 우열을 뜻하지 않습니다.

## 랭킹 사용 범위

분석 당시 게임 내 일간·주간·역대 솔로 상위 50과 주요 후보의 포켓몬별 표를 참고했습니다. 기간별 표에는 같은 기록이 겹칠 수 있어 합산하지 않았습니다. 랭킹에는 당시 기술·아이템·강화·게임 버전이 없으므로 동일 강화 상태의 검증 자료로 취급하지 않습니다. 실시간 랭킹 연동이나 플레이어 정보 수집도 하지 않습니다.

45:00은 공개된 서버 규칙의 저장 허용 상한입니다. 이 기록 하나만으로 최고 티어나 부정 기록을 확정하지 않습니다. 전체 전투 시뮬레이션, 실전 승률 검증, Windows 실기기 검증을 완료했다는 의미도 아닙니다.
