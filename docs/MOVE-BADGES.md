# 포켓몬별 기술 추천 배지 · 패치0.4.9

도감의 시작 기술·기술 아이콘, 강화의 시작/제외 기술 선택, 기술 단축키 선택지에 작은 배지를 붙입니다. 별도 패널·메뉴·플레이 수치 변경은 없습니다.

- `다A·보S`: 다수전 A / 보스전 S. 직접 공격이 아닌 여섯 지원 기술은 `지원S` 또는 `지원A`입니다.
- `특수적합`/`물리적합`: 해당 종의 더 높은 공격 계수 쪽. 반대쪽은 `특수보조`/`물리보조`, 동률은 `균형형`입니다. 지원은 물리·특수·방어·이동·회복으로 표시합니다.
- 단일 타입 포켓몬의 같은 타입 **직접 공격에만 +20%**가 적용됩니다. 이중 타입에는 일반적인 다른 포켓몬 게임의 자속 보너스를 가정하지 않습니다. 버프·회복·독 비례피해·제어 효과를 직접피해 계수로 환산하지 않습니다. 세부 사항은 배지 설명에 있습니다.
- 역할 등급은 Lv5·영구강화 최대 가정의 비공식 잠정 추천입니다. 포켓몬 적합도를 별도로 표시하며 같은 타입이라는 이유로 S 승급, 약한 공격 계수라는 이유로 일괄 강등하지 않습니다. 실제 승률·DPS·전투 시뮬레이션 결과가 아닙니다.

## 안전 범위

강화에서는 화면의 포켓몬 선택값, 도감에서는 보이는 실제 포켓몬 이름과 번호를 대조합니다. `???`·잠긴 도감·알 수 없는 포켓몬은 배지를 붙이지 않습니다. 등록되지 않은 기술은 중립 `미평가`입니다. 이름 원문·검색어·닉네임·옵션 값·선택 상태·아이콘·기존 클릭 동작을 보존합니다. 저장·계정·쿠키·인증정보를 읽거나 바꾸지 않습니다.

게임 중 레벨업 신규·강화·진화 카드, 유대 선택 카드와 최신 일시정지의 기술명 열도 DOM 배지 대상입니다. 현재 포켓몬·버프·계정·저장 상태나 마지막 메뉴 선택값은 읽거나 추정하지 않으므로 게임 중에는 **중립 기술 추천만** 표시합니다. 전투 Canvas HUD/스킬 칸은 제외하며 실제 iPhone Safari/Userscripts와 설치 확장 전체 E2E는 미검증입니다.

## 근거와 검증

- 역할 추천 원본: `018e986f4c12f414dfa84193ee35b2959b1e325c`, 103개 기본 기술. 잠정 편집 판단이며 합산 점수가 아닙니다.
- 종별 물리/특수 계수·타입·단일타입 효과 확인: 최신 원본 `3c9641c9e782cf74afbde490f39cd60adf59e32b`.
- 최신판은 일부 유도·튕김 기술의 기본 투사체 수/퍼짐과 협동 처리를 고쳤습니다. 이름·타입·물특 분류·피해·종별 계수·단일타입 규칙·관련 메뉴 식별자는 유지됐습니다. 역할 등급은 변경하지 않았습니다.
- `tests/test-move-data.cjs`: 966종×103개 조합의 원본 `Stats.fit`/`Player.atkFor`와 397,992개 검사. 계정·세이브·실전 시뮬레이션을 사용하지 않습니다.
- `tests/test-move-tier-ui.cjs`: 가짜 DOM에서 숨김·닉네임·동명 매칭·알 수 없는 기술·선택값·원문·아이콘·재주입·인증 경로 보호.
- 실제 게임 DOM 미리보기에서 뮤츠의 특수 적합, 다투곰의 물리 적합 및 단축키 원값/선택 상태를 확인했습니다. 물리 Safari 검증은 아닙니다.

## 아르세우스는 잡을 수 있나요?

- **30분 심판의 추격자:** 처치 불가. 일반 Enemy가 아닌 별도 객체로 HP/피격 함수가 없고, 일반 공격 대상에 들어가지 않습니다. 접촉 시 플레이어의 무적도 해제하고 최대 체력 비례피해를 줍니다. 기술의 보스전 등급은 이 추격자를 처치할 수 있다는 뜻이 아닙니다.
- **내 포켓몬으로 획득:** 현재 소스에서 아르세우스(493)는 신오4세대·5성이고 스프라이트가 존재해 `Gacha.pool(5,4)`에 포함됩니다. 5성 중 하나이지 아르세우스 확정 뽑기는 아닙니다. 실제 티켓 뽑기는 실행하지 않았습니다.

검증 자료는 해시를 고정한 `tests/fixtures/move-context-current/`에 보존합니다. 게임 라이선스와 출처는 기존 고지를 유지합니다.


## 게임 중 DOM 배지 · 0.5.1

- `#scr-levelup #cards`의 신규/강화/진화 기술 카드만 판정합니다. 일반 능력치 강화·아이템·보상·사용자 입력에는 붙이지 않습니다.
- `#scr-bond #bond-cards`의 기술과 `#scr-pause #pause-sum .sum-moves`의 첫 기술명 열을 지원합니다. 피해량·DPS·플레이어 능력치 열을 읽거나 변경하지 않습니다.
- 103개 기본 기술과 97개 진화 경로를 원어/영어/한국어 별칭으로 대조합니다. 진화 제안은 기본→진화 쌍이 유일해야 하고, 강화·유대·일시정지는 표시 이름이 유일해야 합니다. 철제광선·폭풍 등 동명 진화를 이름 하나로 임의 연결하지 않습니다. 알 수 없거나 모호한 기술은 회색 미평가입니다.
- 진화의 역할 등급은 기존 기술 계열 잠정 평가를 보수적으로 유지합니다. 현재 레벨, 실측 승률·DPS 또는 새로운 전투 시뮬레이션 결과가 아닙니다.
- **포켓볼 묶음 + 등급 = 다수전**, **왕관 + 등급 = 타격 가능한 보스전**입니다. 아이콘·텍스트 등급을 별도 작은 배지로 나누며 접근성 레이블과 제목 설명을 둡니다. 지원 기술은 공격 등급과 별도로 표시합니다. 네이티브 select 옵션은 아이콘 대신 다/보 텍스트를 유지합니다.
- 픽셀 아이콘은 고정 원본 `3c9641c9e782cf74afbde490f39cd60adf59e32b`의 `js/ui/icons.js` ball/crown에서 재사용했습니다. PolyForm Noncommercial 1.0.0 / Copyright 2026 JPTER78. SHA-256 및 출처는 `data/move-ui.json`의 `roleIconSource`에 기록합니다. 번들 내 data SVG라 외부 이미지/원격 실행 JS를 추가하지 않습니다.
- 원래 이름·아이콘·태그·키보드 번호·onclick/선택 콜백을 보존하며 카드 재추첨·협동 대기·숨김/재표시·DOM 교체에서 배지를 재평가합니다. 게임 함수나 evolve를 실전 객체에 호출하지 않습니다.
