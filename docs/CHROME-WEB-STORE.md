## 자동 업데이트는 언제 되나요?

스토어 심사 통과 후 **스토어에서 설치한 확장**은 Chrome의 공식 확장 업데이트 절차로 갱신됩니다. 모든 사용자의 즉시 업데이트를 보장하는 기능이 아니며, 새 코드가 이미 열린 게임에 적용되려면 게임 새로고침이 필요합니다.

현재 GitHub ZIP을 압축 해제해 설치한 기존 확장이 자동으로 스토어판으로 전환되는 것은 아닙니다. 게시된 스토어판으로 **한 번 설치 전환**하고, 기존 압축해제 확장을 꺼서 중복 실행을 막아야 합니다. 현재 설치판이나 게임 데이터를 삭제할 필요는 없습니다. 스토어 설치 링크는 실제 게시 확인 후 안내합니다.

공식 지원 배포 방식 및 자동 업데이트: https://developer.chrome.com/docs/extensions/how-to/distribute
