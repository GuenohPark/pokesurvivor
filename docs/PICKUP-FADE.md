# 따라오는 보상 투명화

## 동작과 대상

공통 패치 0.5.2부터 게임의 그리기에 접근할 수 있는 환경에서 자동으로 켜집니다. **끌려오는 경험치·큰 경험치·코인·회복 아이템만 가까워질수록 점차 옅어집니다.** 게임 좌표 거리 140 이상에서는 원래 불투명도, 20 이하에서는 20%를 유지하며 중간은 부드럽게 변합니다. 그림자·빛번짐·본체 모두 같은 비율로 처리합니다.

바닥에 놓인 보상, 티켓·장비·폭탄·자석, 포켓몬·적·탄막은 그대로 보입니다. 협동전에서는 보상의 소유자를 판정하지 않고 현재 화면의 내 포켓몬과의 시각적 거리만 사용합니다.

## 공통 코드와 기기별 제한

구현은 하나의 `src/pickup-fade-ui.js`입니다. 통합판·기존 메뉴/브라우저판의 공통 빌드와 별도 확장 MAIN 실행에도 같은 소스를 넣습니다. 같은 코드가 전달된다는 것이 모든 환경의 실행 권한까지 같다는 뜻은 아닙니다.

**아이폰 Safari + 무료 Userscripts에서는 게임 Canvas 그리기에 접근할 수 없어 이 효과는 미지원입니다.** 기본 설치 경로와 기존 DOM 번역·검색·배지는 유지합니다. CSP를 끄거나 우회하지 않으며, 전체 Canvas를 흐리게 하지 않습니다.

## 안전 경계

원본 `G.Pickups.draw`를 한 번 그대로 호출하면서 그리기 투명도만 곱합니다. 첫 유효한 그리기에서 목록 순서와 `Camera.sees` 인자를 확인하고 구조가 맞지 않으면 페이드를 끕니다. 카메라 가시성 함수의 호출 대상·인자·결과를 보존하며 호출 직후 복원합니다. 그리기 마지막의 투명도 초기화도 보존합니다.

읽는 값은 보상 종류·끌림 여부·그리기 좌표와 내 포켓몬의 x/y뿐입니다. 체력·능력치·강화·버프·계정·세이브는 읽지 않으며, 위치·속도·보상 값·획득 반경·획득 처리·서버 요청은 바꾸지 않습니다.

## 검증과 남은 범위

- 고정 원본 pickup.js/icons.js와 합성 객체로 Node 검사 31그룹. 원본과 이동·획득 결과, 수집한 합성 보상·수치를 비교합니다. [검사 보고서](../tests/reports/pickup-fade-tests.json)
- 로컬 Chromium에서 실제 Canvas 2D와 원본 아이콘 그리기로 29검사. 첫 확인 프레임은 원본과 픽셀 동일, 이후 가까운 대상 영역만 변경되며 비대상·바닥·원거리 영역은 동일합니다. [브라우저 보고서](../tests/reports/pickup-fade-browser.json)
- 위 검사는 실제 공식 게임의 플레이, 설치형 Tampermonkey/확장, 물리 iPhone/Android, 로그인·클라우드 저장의 종단간 검증이 아닙니다.

적용은 진행 중인 판을 마친 뒤 패치 업데이트와 새로고침으로 합니다. 아이폰 자동 로더 0.1.2는 바뀌지 않으며 다시 설치할 필요가 없습니다. 업데이트 확인은 관리자·캐시·권한에 따라 지연될 수 있습니다.
