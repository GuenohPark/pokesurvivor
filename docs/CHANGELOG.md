# 변경 이력

## 0.5.5 · 상점·가방·성격·특성·기술머신 호환성

- 켈리몬 상점·가방·민트·일반/숨겨진 특성 캡슐·기술머신 및 새 알림·업데이트 안내182항목을 추가합니다.
- 25성격·271특성의 공식 한국어 명칭은 전용 문맥으로만 번역하고 닉네임·선택 ID·수량·콜백을 보존합니다.
- 기술머신 Psychic은 사이코키네시스, 타입은 에스퍼로 구분합니다. 두 번째 시작 기술과 무작위 선택의 표시를 보완합니다.
- 기본 데이터 추천이 성격·선택 특성·TM 학습을 반영하지 않는다는 제한을 명시하며 등급 데이터는 변경하지 않습니다.
- 브라우저/Chrome 수동판0.1.13, 자동 로더0.1.2 유지. 기존 APK·서명키·버전별 배포물·스토어 제출본을 보존합니다.
- 고정 원본 데이터·회귀·격리 DOM UI 검증이며 실제 구매·계정·클라우드·실기기 설치를 검증한 것은 아닙니다.

## 0.5.1 · 게임 중 기술 추천과 역할 아이콘

- 레벨업 신규/강화/진화 기술 카드, 유대 선택, 최신 일시정지 기술명 DOM에 중립 추천을 표시합니다. 일반 능력치 강화·아이템·보상·피해량/DPS 열은 제외합니다.
- 다수전은 게임의 픽셀 포켓볼 묶음, 보스전은 왕관을 쓰는 별도 작은 배지로 표시합니다. 아이콘은 번들 내 SVG이며 출처·SHA·라이선스를 기록합니다.
- 97개 진화 경로를 기본→진화 쌍으로 검증하고 동명 진화의 단독 이름은 미평가로 남깁니다. 실전 포켓몬·계정·저장·버프를 읽지 않고 선택 콜백·숫자·아이콘을 보존합니다.
- 아이폰 Safari + 무료 Userscripts 자동 로더 0.1.2는 유지합니다. 공통 번역팩 0.5.1 / Chrome·브라우저 별도 수동판 0.1.9. 전투 Canvas HUD/스킬 칸과 실기기 전체 흐름은 여전히 별도 검증 대상입니다.
- 게임 중 DOM 11그룹·진화 경로 대조·전체 회귀 및 Chrome58 검사를 추가/유지합니다. 오프라인 실제 렌더러 브라우저 검사는 계정·실기기 E2E가 아닙니다.
