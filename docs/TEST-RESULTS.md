# 통합판 0.5.0 검증 결과

## 완료한 자동 검사

`npm run build`, `npm test`, `npm run test:chrome`를 실행했습니다. Node 내장 모듈만 사용합니다.

- 공통 번들: 10개 검사 그룹. 메타데이터/공통 입력 지문, 초기 대기·중복·채널 충돌, SPA/BFCache/루트 재마운트, 인증 경로 중단/복귀, Canvas·대화상자 원본 호출·반환 보존, lookbehind 없는 문장 경계.
- 정적 설치 페이지: 14개 그룹. 참고용 기기 추정·수동 전환·키보드·JS 없는 설치 링크·URL/접근성·외부 코드/추적 없음.
- 릴리스: 버전 단조 증가, 사람의 manifest/확장 문서 변경 검증, 문서 전용 변경, 변경된 현재 생성물만 스테이징, 과거 버전 ZIP/APK 보호, 워크플로 토큰/루프 제한.
- Chrome 확장 58개 경계/VM 검사. 현재 브라우저 번들과 바이트 일치하고 소스 입력·결과 SHA-256을 빌드 지문과 비교합니다.
- 기존 번역·도감·폰트·패키지·자동로더 검사를 유지했습니다. 기술 적합도 397,992개, 번역 카탈로그 3,799개, 포켓몬 수치 34,815개와 피격/공간 29,965개 검사도 유지합니다. 이는 승률·DPS 실전 시뮬레이션이 아닙니다.

## 실제 브라우저에서 확인한 범위

Aside의 Chromium에서 공식 `.com/dev.html` 문서에 완성 통합본을 직접 실행했습니다. Tampermonkey 설치를 경유한 검사는 아닙니다.

- 기존 패치가 있으면 `other-patch-active`로 중복 초기화하지 않았습니다.
- 새 문서에서 공통 런타임 0.5.0과 번역·폰트·팁·검색·배지가 초기화됐습니다.
- 재실행 시 런타임 객체와 Canvas 후크가 동일했고 폰트·팁·검색 요소가 하나씩 유지됐습니다.
- 각 UI 재마운트 훅을 호출해 오류가 없었고 한국어 검색 선택이 원본 게임 검색어로 전달됐습니다.
- 도감 시작 기술과 기술 아이콘 배지를 확인하고, 기술이 아닌 공격 성향 설명에는 배지가 없음을 확인했습니다.
- 현재 JS 영역의 Canvas `measureText`가 번역된 문자열을 측정했습니다. 이것만으로 모든 관리자에서 게임 Canvas에 도달한다고 증명하지 않습니다.
- 기존 로그인 UI는 계속 보였지만 새 로그인, 저장 버튼 클릭, 클라우드 저장·복원, 전투 시작은 실행하지 않았습니다.
- 설치 페이지는 Chromium의 실제 360/768/1440px iframe CSS 뷰포트에서 가로 넘침이 없고 수동 기기 탭이 작동했습니다. 실제 Android/iPhone 또는 Safari 엔진 검사가 아닙니다.

## 미검증

- PC Windows/macOS 각 Chrome·Edge·Firefox에 Tampermonkey를 설치한 전체 E2E.
- Android Firefox 실기기, iPhone Safari 실기기의 확장 권한·CSP/격리 영역·Canvas·터치 전체 흐름.
- 신규 로그인과 실제 계정/클라우드 저장 왕복. 코드에서 인증/쿠키/계정 저장 API를 추가하지 않았다는 정적 증거와 실제 성공은 다릅니다.
- 각 관리자의 자동 업데이트 시간. 메타데이터·버전 계획은 검사했지만 관리자·절전·승인·CDN·설정에 따라 확인과 적용이 지연됩니다.
