# 제단 돌 받침의 이름 표시

공통 패치 0.5.3부터 보석 아래 돌 받침에 다음 이름을 표시합니다.

- 빨강: **분노**
- 하늘색: **질주** (이동속도 효과, 기술 10만볼트와 구분)
- 분홍: **자석**
- 노랑: **신속함**
- 사용한 제단: 밝은 회색 **사용함**

원본 돌 받침 안에 짧은 글자만 얹습니다. 버프의 수치·25초 지속시간·종류·사용 여부·충돌·접촉 판정은 바꾸지 않습니다. 실제 제단을 사용하거나 게임을 자동 진행하지 않습니다.

## 구현과 지원

`src/altar-label-ui.js`가 통합·메뉴·브라우저 공통 빌드 및 기존 확장 MAIN 실행 경로에서 재사용됩니다. 공개 `World.drawProp`의 원래 호출·인자·반환·예외를 보존하고 그리기가 끝난 뒤 작은 이름을 추가합니다. 글자의 Canvas 상태는 save/restore로 복원하며, 이름 그리기 오류는 원본 게임에 전파하지 않습니다. 알 수 없는 종류는 표시하지 않습니다.

읽는 값은 제단의 타입·종류·사용 여부·그리기 좌표와 정적 픽셀 배율뿐입니다. 플레이어·능력치·계정·세이브는 읽지 않습니다. **아이폰 Safari + 무료 Userscripts에서는 게임 Canvas에 접근할 수 없어 이 기능도 미지원**이며 기존 DOM 기능과 기본 설치 경로는 유지합니다. CSP를 해제하거나 우회하지 않습니다.

## 검증

고정 원본 world.js/tiles.js는 공개 커밋 및 현재 제공 파일과 바이트가 일치합니다. 합성 제단으로 전용 Node 29검사를 통과했습니다. [검사 보고서](../tests/reports/altar-label-tests.json). 실제 Canvas와 내장 글꼴로 오프라인 286검사 및 40개 사례에서 글자가 돌 받침 안에 들어가는 것을 확인했습니다. [화면 검증 보고서](../tests/reports/altar-label-browser.json). 이 검사는 설치 관리자·실제 게임 플레이·로그인·세이브·물리 기기 검증을 뜻하지 않습니다.

공통 패치 업데이트는 판을 마친 뒤 적용하세요. 아이폰 자동 로더 0.1.2는 그대로이며 다시 설치할 필요가 없습니다.
