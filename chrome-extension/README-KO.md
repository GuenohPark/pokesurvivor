# PokéSurvivor 한국어 패치 · Chrome 시험판

Windows 10/11 및 macOS의 Chrome 111 이상용 Manifest V3 확장프로그램입니다. Windows용 별도 실행파일이나 APK가 필요 없습니다. 실제 Windows 기기 검증 여부는 TEST-REPORT.json을 확인하세요.

## Windows 설치

1. ZIP을 다운로드하고 고정 폴더(예: 문서\PSKO-Chrome)에 **모두 압축 해제**합니다. ZIP이나 JS 파일 자체를 선택하는 것이 아닙니다. 설치 후 이 폴더를 삭제하지 마세요.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 **manifest.json이 바로 들어 있는 폴더**를 선택합니다. 폴더 안에 폴더가 더 있으면 manifest.json이 있는 안쪽 폴더를 선택하세요.
5. https://pokesurvivor.com/ 또는 https://www.pokesurvivor.com/ 를 열거나 기존 게임을 새로고침합니다. 진행 중인 판에서 새로고침하면 상태가 초기화될 수 있습니다.

Mac도 같은 방식이며 ZIP을 풀고 같은 manifest 폴더를 선택합니다. Android Chrome은 이 데스크톱 확장 설치 대상이 아닙니다. 회사/학교에서 개발자 모드를 막은 경우 정책을 우회하지 마세요. Chrome Web Store 심사 대기 중이며, 승인·게시 확인 전에는 스토어에서 설치할 수 없습니다. 이 안내는 압축해제 설치판용입니다. CRX를 더블클릭해 설치하는 방식이 아닙니다.

## 지원 범위

- 공식 .com 두 호스트의 HTTPS 최상위 게임 경로 `/`, `/index.html`, `/dev.html`에만 적용합니다. .org 등 별개 사이트, Google/Firebase, 인증 경로, 하위 프레임과 빈 팝업은 제외합니다.
- 메뉴·포켓몬 이름·설명 DOM, Canvas 텍스트와 내장 한국어 글꼴을 포함합니다. 한국어 데이터 0.4.10, 기존 브라우저 스크립트 0.1.7과 도감 풀강화 티어 UI를 포함했습니다.
- 기존 Tampermonkey/Userscripts 번역 패치나 별도 번역 확장은 중복으로 켜지 마세요.
- 계정·키보드·Google 로그인을 재구현하지 않습니다. 원래 Chrome과 공식 사이트의 로그인 흐름을 그대로 사용합니다. 로그인 성공을 보장하지 않습니다.
- 별도 특수 권한, 서비스 워커, 외부 코드 다운로드, 원격 분석, 쿠키/토큰 복사나 UA 변경이 없습니다. MAIN world는 Canvas 글꼴·문자열 변환을 위해서만 사용합니다. 사이트 자체 스크립트와 같은 실행 환경이므로 사이트 코드가 번역 코드에 영향을 줄 수 있습니다.
- 이 ZIP은 설치 파일이자 전체 확장 소스입니다. 번역팩은 내장형이고 개발자 모드 설치판은 자동 업데이트되지 않습니다. 새 파일로 교체 후 확장 관리의 새로고침 및 게임 새로고침이 필요합니다.

## 사용 중지·삭제

`chrome://extensions`에서 이 확장을 끄거나 삭제한 뒤 게임을 새로고침하세요. 이미 실행된 페이지의 DOM/Canvas 변환은 확장을 끄기만 해서는 원상 복구되지 않습니다. 게임의 로컬 저장이나 Chrome 프로필을 초기화할 필요는 없습니다.

## 라이선스

비공식 비상업 팬 패치입니다. 원본 고지와 라이선스는 content-main.js, THIRD-PARTY-NOTICES.md 및 licenses/에 보존했습니다.

## 도감 풀강화 잠정 티어

메인 파트너·도감 등 확인된 포켓몬 이름 요소 옆에 작은 S / A+ / 화력 / 미평가 배지를 붙입니다. 별도 티어 메뉴·풀강화 수치 패널은 없습니다. 평가되지 않은 포켓몬에는 중립 미평가 배지를 붙이며, 미보유 ???는 그대로 숨깁니다. 966종 수치 중 14종만 잠정 평가했습니다.

현재 계정 강화나 저장 데이터를 읽거나 변경하지 않는 참고 UI입니다. 등급은 비공식 잠정 후보군이며 실제 DPS·승률이나 랭킹 공식 등급이 아닙니다. [평가 기준과 계산표](https://github.com/GuenohPark/pokesurvivor/blob/main/docs/TIERS.md).

기존 0.1.0 설치자는 새 ZIP을 풀어 기존 확장 폴더를 교체하고 확장 관리의 새로고침을 누른 뒤, 진행 중인 판을 마친 후 게임도 새로고침하세요. 이 압축해제 설치판은 자동 업데이트되지 않습니다.

## 피격 크기 재평가

S 후보는 뮤츠·게을킹·전수목입니다. 실제 피격 반지름·일반 탄환의 선형 기하 모형·지형 감속·기술 풀을 재검토했으며, 고정 가중치 종합 점수나 실전 승률로 확정한 등급이 아닙니다. [재평가 기록](https://github.com/GuenohPark/pokesurvivor/blob/main/docs/TIER-REEVALUATION.md)을 확인하세요. 이름 옆 작은 배지 UI는 그대로이며, 티어 메뉴·수치 패널은 추가하지 않았습니다.

## 스토어와 구분

이 안내의 GitHub 수동 설치판은 0.1.7 / 패치 0.4.10입니다. 현재 Chrome Web Store 제출본은 별도 0.1.3 / 패치 0.4.6이며 이번에 기존 심사를 취소하지 않았습니다. Safari 사용자는 Chrome ZIP 대신 기존 자동 로더를 그대로 사용하면 됩니다.
